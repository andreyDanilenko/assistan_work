# Задачи проекта

Локальные карточки для переноса в трекер. `LOKI-*` — наши обозначения, внешние задачи в Яндекс Трекере не создавались. Исполнители, даты завершения и сроки не выдуманы.

Приоритет на 11 октября: **дать сотруднику простую рабочую версию с компьютера**. Дальнейшая детальная декомпозиция приостановлена по запросу владельца. Начните с [приемки первой версии](prototype.md), [инструкции запуска](../QUICKSTART.md) и [сборки комплекта](../spec/distribution.md).

## Первая версия

`Loki → SQLite (48 часов) → фильтры и группы → короткое сообщение Telegram`.

Уже реализованы `watch`, `telegram-chats`, очередь повторной доставки, антиспам, периодическая сводка и контроль отсутствия логов. Краткий анализ основан на правилах, без LLM. JSON хранит состояние и очередь. [SQLite-архив](sqlite.md) сохраняет исходные логи за последние 48 часов; накопление идет во время работы приложения.

Осталось выполнить приемку с действующим доступом, выбранной группой и на компьютере сотрудника. Это отмечено незакрытыми пунктами в карточке.

## Позже

PostgreSQL с полной историей, входящие команды бота, REST, админка, сервер/сокет и LLM обсуждаются после пробного использования. [Kafka](backlog/KAFKA.md) — отдельная отложенная оценка и не входит в основной поток.

При переносе карточки в трекер заголовок становится названием задачи; тип, статус, приоритет и компонент — полями. Текст и чек-листы копируются в описание, зависимости связываются после появления настоящих ключей задач.
