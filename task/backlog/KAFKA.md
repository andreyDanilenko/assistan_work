# Kafka: отдельная оценка после прототипа

- **Статус:** Отложено
- **Приоритет:** Низкий
- **Основной поток:** не зависит от этой задачи.

Сейчас Kafka в проекте нет. После первой версии выяснить, есть ли источник, готовый публиковать события, и нужна ли очередь по объему/задержке. Сравнить ее с получением из Loki, описать повторную доставку, offsets и восстановление. Результат — обоснованное решение о необходимости, затем отдельные задачи реализации. PostgreSQL остается планируемым хранилищем истории; разворачивать брокер сейчас не требуется.
