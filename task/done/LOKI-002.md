# LOKI-002 Загрузить и проверить настройки Grafana Loki и Telegram

> Карточка фиксирует результат раннего этапа. Возможности первой версии Telegram описаны в [текущей приемке](../prototype.md).

- **Тип:** Задача
- **Статус:** Выполнено
- **Приоритет:** Средний
- **Компонент:** Конфигурация
- **Этап:** Выполнено
- **Зависимости:** [LOKI-001](LOKI-001.md)

## Цель

Подготовить понятную настройку доступа без паролей в коде и без зависимости компонентов от глобального окружения.

## Что сделано

- [x] Добавлены `.env.example`, модель настроек и `config.Load`.
- [x] Зафиксирован порядок: значения по умолчанию → файл → переменные окружения, включая явно пустое значение.
- [x] Настроены адрес Grafana, UID источника, организация, метка `app` и проект `sds-orders`.
- [x] Токены Grafana и Telegram разделены; обязательность проверяется для выбранной команды.
- [x] Файл читается как буквальные `KEY=value`: без shell, исполнения команд и подстановок.
- [x] Ошибки неверного URL, UID, токена и файла не раскрывают чувствительные значения.

## Критерии приемки

- [x] Окружение перекрывает файл; пустой токен не заменяется незаметно старым значением из файла.
- [x] Неизвестные и повторяющиеся настройки, поврежденные кавычки и слишком большой файл отклоняются.
- [x] `telegram-check` не требует токена Grafana; анализ файла не загружает `.env`.
