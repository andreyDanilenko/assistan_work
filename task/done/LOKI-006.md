# LOKI-006 Добавить CLI для проверки доступа и ручного получения логов

> Карточка фиксирует результат раннего этапа. Возможности первой версии Telegram описаны в [текущей приемке](../prototype.md).

- **Тип:** Задача
- **Статус:** Выполнено
- **Приоритет:** Средний
- **Компонент:** CLI
- **Этап:** Выполнено
- **Зависимости:** [LOKI-002](LOKI-002.md), [LOKI-004](LOKI-004.md)

## Цель

Дать пользователю последовательную ручную проверку доступа и ответов Loki до подключения обработки.

## Что сделано

- [x] Добавлены команды `check`, `labels`, `values`, `projects`, `logs` и `query`.
- [x] Поддерживаются выбор проекта, относительный или явный период, лимит страницы, таймаут и файл настроек.
- [x] По умолчанию выводится краткая сводка; `--raw` явно включает исходный JSON.
- [x] Разбор аргументов отделен от выполнения сервиса и форматирования ответа.
- [x] Справка работает без токенов; ошибки аргументов и отмена имеют отдельные коды завершения.

## Критерии приемки

- [x] Некорректный период, несовместимые аргументы и превышение допустимого лимита отклоняются.
- [x] Команда передает проект, период и лимит сервису без скрытого запуска анализатора.
- [x] Сводка не печатает сырые сообщения и предупреждает о заполненной странице.
- [x] Вывод и коды завершения проверяются с подставным исполнителем.

## Границы задачи

Сетевые команды выполняют по одному запросу. Суточной догрузки и расписания в CLI пока нет; `--raw` может показать чувствительное содержимое исходных логов.
