# LOKI-008 Читать сохраненный JSON Loki и текстовый экспорт Grafana

> Карточка фиксирует результат раннего этапа. Возможности первой версии Telegram описаны в [текущей приемке](../prototype.md).

- **Тип:** Задача
- **Статус:** Выполнено
- **Приоритет:** Средний
- **Компонент:** Входные данные
- **Этап:** Выполнено
- **Зависимости:** [LOKI-007](LOKI-007.md)

## Цель

Разбирать выгрузки локально, чтобы проверять данные и правила без токенов и повторных запросов к Loki.

## Что сделано

- [x] Источник `LokiFileSource` принимает JSON-ответ Loki и текстовый экспорт Grafana.
- [x] Формат определяется по содержимому; поддерживаются BOM и строки с CRLF.
- [x] Для TXT проверяются заголовки, строковые `Common labels` с непустой `app` и совпадение двух представлений времени.
- [x] Сообщение после первых двух табуляций сохраняется без изменения; дубликаты не удаляются.
- [x] Введены пределы 10 МиБ и 100 000 записей, отмена через контекст и безопасные ошибки с номером строки.

## Критерии приемки

- [x] Поврежденный формат не выдает частично разобранную выборку как успешный результат.
- [x] Исходная точность времени, доступные метки и metadata сохраняются.
- [x] Превышение ресурсов, неподходящий путь и неверные заголовки отклоняются без раскрытия содержимого.

## Границы задачи

TXT содержит только доступные в экспорте общие метки; индивидуальные pod и серверы из них не восстанавливаются. Успешный разбор файла не доказывает полноту выбранного в Grafana периода.
