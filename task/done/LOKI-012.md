# LOKI-012 Инициализировать Telegram бота и проверить его через getMe

> Карточка фиксирует результат раннего этапа. Возможности первой версии Telegram описаны в [текущей приемке](../prototype.md).

- **Тип:** Задача
- **Статус:** Выполнено
- **Приоритет:** Средний
- **Компонент:** Telegram
- **Этап:** Выполнено
- **Зависимости:** [LOKI-002](LOKI-002.md), [LOKI-003](LOKI-003.md)

## Цель

Проверить, что сохраненный токен принадлежит нужному Telegram-боту, отдельным небольшим сценарием.

## Что сделано

- [x] Добавлен клиент `telegram.Client` с явными настройками и внедренным HTTP-клиентом.
- [x] Конструктор проверяет полный формат токена «цифры:секретная часть» без сетевого запроса.
- [x] Метод `GetMe` получает и проверяет сведения о боте; модель `BotInfo` содержит ID, username, имя и признак бота.
- [x] Команда `telegram-check` выводит подтвержденные сведения и завершает работу.
- [x] Настройки Telegram независимы от Grafana; чувствительные детали URL и ответа скрыты в ошибках.
- [x] Пользователь подтвердил успешную проверку рабочего бота.

## Критерии приемки

- [x] Проверка делает один `getMe` и не отправляет сообщения.
- [x] Неверный токен, ошибочный ответ, превышение размера, отмена и таймаут обрабатываются безопасно.
- [x] Сценарий проверяется через подставной HTTP-клиент без рабочего Telegram.

## Границы задачи

`sendMessage`, получение обновлений, команды, кнопки, уведомления, `chat_id` и списки разрешенного доступа еще не реализованы. Успешный `getMe` не подтверждает возможность отправки в выбранную группу.
