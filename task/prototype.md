# LOKI-017 Первая версия мониторинга для сотрудника

- **Тип:** Задача
- **Статус:** К приемке
- **Приоритет:** Высокий
- **Результат:** запуск с компьютера и понятные сообщения Telegram без потока сырых логов.
- **Зависимости:** [Loki](done/LOKI-005.md), [модели](done/LOKI-007.md), [проверка бота](done/LOKI-012.md).

## Границы

Работает пока компьютер включен, не спит и имеет сеть. Отчеты относятся к последнему окну, не суммируют сутки/час между ними. SQLite-архив исходных событий до 48 часов добавляется отдельно в [LOKI-018](sqlite.md); JSON продолжает хранить очередь и антиспам. Анализ архива и поиск прошлых заказов через команды Telegram, PostgreSQL, REST и LLM в эту поставку не входят. Неоднозначный сетевой ответ Telegram допускает редкий повтор доставки.
