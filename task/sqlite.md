# LOKI-018 Локальный архив SQLite на 48 часов

- **Тип:** Задача
- **Статус:** Реализовано, локальные проверки пройдены
- **Результат:** обычный `watch` сохраняет исходные события без отдельного сервера базы.
- **Зависимость:** [прототип](prototype.md).

## Реализация

- [x] Создавать базу по `WATCH_DB_FILE`, по умолчанию `local/loki.db`.
- [x] Сохранять исходную строку, timestamp, метки и metadata до фильтров.
- [x] Не увеличивать количество событий при повторе окна; сохранять кратность одинаковых записей.
- [x] Оставлять не более 48 часов по времени Loki, очищать при запуске и каждом цикле; не добавлять уже устаревшие события.
- [x] Сохранить JSON очереди/антиспама и режим предпросмотра без записи.
- [x] Добавить `db-status` и `db-cleanup` без токенов; обе команды создают и обслуживают базу перед статистикой.
- [x] Включить лицензии зависимостей в переносимые комплекты.

## Проверки приемки

- [x] Проверить повторное окно, одинаковые события, точность времени, полный контекст и перезапуск.
- [x] Проверить очистку на границе 48 часов, при недоступном Loki и после перерыва работы.
- [x] Проверить отсутствие файлов и изменений базы после `--dry-run`.
- [x] Выполнить тесты, проверку кода, сборку darwin-amd64 и проверку состава архива. Сборки остальных платформ отложены.

## Границы

Архив накапливается во время работы; прошлые 48 часов автоматически не загружаются. Telegram анализирует прежнее окно 10 минут. Пока процесс выключен, очистка не выполняется. Фиксированного ограничения размера файла нет; база содержит незашифрованные исходные данные.

[Быстрый запуск](../QUICKSTART.md), [описание хранения](../README.md), [поставка](../spec/distribution.md).

Проверено: `go test ./...`, `go vet ./...`; отдельный race-прогон config/monitor/cli; запуск `db-status` и `db-cleanup` из распакованного darwin-amd64 комплекта без токенов. Проверка на компьютере сотрудника и рабочей группе Telegram остается в карточке прототипа.
